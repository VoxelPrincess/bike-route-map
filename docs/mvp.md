# MVP — bike-route-map

## 1. What is the MVP?

The Minimum Viable Product (MVP) is a basic map-based web tool that allows users to:
- View bike routes on a map
- Filter segments by surface type (asphalt, gravel, etc.)
- See color-coded route segments
- Click or hover to see surface information

## 2. Why this MVP?

This version helps validate the concept that surface type awareness improves cycling experience.  
It focuses on frontend interactivity and visual clarity.

## 3. What’s included in MVP

- React + Leaflet map centered on Helsinki
- Static GeoJSON sample data
- Interactive filter UI for surface types
- Colored segment rendering
- Surface popups on hover

## 4. Not included (yet)

- Real routing from A → B
- Backend or API integration
- Data storage or user profiles
- Mobile optimization
