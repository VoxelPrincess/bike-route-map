# Problem Domain — bike-route-map

## 1. Context

Cyclists in urban areas often struggle to choose routes that are both efficient and comfortable.  
Standard map services do not provide information about surface types (asphalt, gravel, etc.),  
which can significantly affect safety and comfort — especially in winter, for cargo bikes, or with children.

## 2. Problem

- No easy way to filter bike routes based on surface type.
- Cyclists rely on trial and error or third-party forums.
- Route planners optimize for time, not comfort.

## 3. Goal

Create an interactive web tool that helps cyclists:
- Visualize surface types along their route
- Plan better trips using open data
- Eventually give feedback or report issues

## 4. Potential Users

- Daily cyclists
- Parents with trailers or cargo bikes
- Newcomers to the city
- City planners and infrastructure teams
